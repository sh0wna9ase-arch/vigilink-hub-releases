# Vigilink Hub

Nx Witness サーバーと同じ PC で動き、機器からの通知の受け付け・ルールによる自動の動作・Modbus 機器の入出力・機器の状態監視などを、ブラウザの管理画面で設定できるソフトウェアです。

このリポジトリは**配布物（インストーラー）の置き場**です。ソースコードは公開していません。

## ダウンロード

[Releases](../../releases) から、お使いの OS に合ったファイルをダウンロードしてください。

| OS | ファイル |
|---|---|
| Windows 10 / 11 / Server 2016 以降（64 ビット） | `VigilinkHub-<版>-x64.msi` |
| Ubuntu 20.04 以降（amd64） | `vigilink_<版>_amd64.deb` |

対応する Nx Witness: 6.1

導入の手順は、インストール後にデスクトップにできる「Vigilink Hub マニュアル」を参照してください。

## English

Vigilink Hub runs on the same PC as an Nx Witness server. It receives notifications from devices, runs automated actions by rules, handles Modbus device I/O, and monitors device status — all configured from a browser-based admin page.

This repository hosts **installers only**. The source code is not public.
